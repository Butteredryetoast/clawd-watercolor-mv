# 踩坑清单（症状 → 原因 → 做法）

十部片（等待、Two Moons、Highway、赤壁、Whiskey、春风吹、遇见、冬天一个游、电动少女、丸之內虐待狂）积累的问题。模板里已修好的标 ✅。

## 画面

| 症状 | 原因 | 做法 |
|---|---|---|
| 字幕底下的灰框一直在闪，边缘有锯齿 | 底带用 p5.brush 水彩画，每秒随抖动重抽 12 次形状和纹理 | ✅ 底带改在合成层画（柔边、按句固定）。不要再用 `paint()` 画字幕底带 |
| 标题卡、大块深色背景在闪 | 同上：大面积高对比的水彩填色每 1/12 秒换一次纹理 | 用 `steady(key, () => …)` 包起来；或整片用 `CONFIG.boil: 0`（清爽版） |
| 光晕有硬边、在深底上发灰 | 单个水彩 fill 有边缘，p5.brush 光谱混色把暖光混成灰 | `softGlow` / `glowDot`：叠几层低不透明度的平涂 |
| 白色笔触变灰 | 浅底上纯白笔触经光谱混色变灰 | 用底色的浅邻近色；高光用 wash |
| 红车身上的白色波浪线（`inkLine`）发灰 | 白笔触压在饱和色上同样被光谱混色 | 白线画成 `paint(ribbonPts(pts, w, w), { wash })` 平涂带（《丸之內虐待狂》丸之内线电车） |
| 深色角色站在深色舞台上看不见 | 和背景同一明度 | 身后加一团冷色 `warmGlow` 逆光 + 一圈浅色轮廓线（《丸之內虐待狂》`idol`） |
| 抱在身前的吉他挡住脸 | 琴身按整条手臂线的长度放大 | 琴身宽约为角色身宽的一半，琴身中心放在握点附近（`guitarAlong` 里 s = L/2.5） |
| 剧情要看到她的脸，但她背对镜头贴着玻璃 | Clawd 只有正面和背影 | 镜头推到玻璃前，在拍点上切到玻璃另一边反打（《丸之內虐待狂》L3） |
| 拱桥下、地平线附近露出一条纸色 | 天空底色只铺到地平线，桥洞里没东西 | 天空底色往下多铺一段，铺过河面 |
| 列车从隧道口钻出来时，车尾露在洞口外的山体上 | 洞口外的遮挡块太窄 | 遮挡块至少和整列车一样长 |
| 屋檐和枝头的积雪推镜时变成灰色胶囊 | 粗 `paint` 笔触随相机一起放大 | `snowLine(pts, h)` 画细雪带 |
| 线条变成点、远处或放大后消失 | p5.brush `isInCanvas()` 用变换前坐标判断，范围太小 | ✅ 用模板里打过补丁的 `vendor/p5.brush.js`，不要换回 npm 版本 |
| 特写里墨线太粗、墨点糊 | 笔宽随相机放大 | ✅ `zsw()` 自动减细；嵌套场景用 `nest()`，它会设 `SCALE_K` |
| 窗里的嵌套场景溢出窗框 | `nest()` 不裁剪 | 先画嵌套场景，再在窗洞四周分 4 块画墙盖住溢出部分，最后画窗框 |
| 墙面笔触像水痕，或者穿过窗户 | 大笔触随机铺满整面墙 | 笔触只铺在开口四周的区域，用短笔触 |
| 伸进画面的手臂像一根棍子 | `armTo` 拉得太长 | 让角色本身走进画面（背影走入），长手臂别超过约 4u |
| 手套 / 持物在错的手上 | 面朝观众时左手是 `aR` | 设定写清“左手 = aR”；背影时反过来 |
| 抱在身前的长道具（雨伞当吉他）手臂看不见 | clawd() 的手臂画在身体后面，手伸向身体内侧就被身体挡住 | 握点放在身体轮廓外：琴头一端在身体外侧，另一只手落在杆上离肩 2.2u 的点（《丸之內虐待狂》`airGuitar`） |
| 关键道具被小角色挡住 | 绘制顺序 | 身后的角色 → 桌面 → 桌上物 → 前景角色；座位附近不放挡道具的东西 |
| 路人撞到主角身上 | 路人和主角在同一深度 | 路人放到后景：y 更高、u 更小、颜色更淡 |
| 背景楼又大又平 | 楼太高、没有层次 | 楼压低，加一排枯树 / 路灯做中景 |
| 香炉的烟像一棵白色的树 | 烟用粗笔 | 细笔（sw 1.2–1.4）+ `curlPath` |
| 霜花像马赛克 | 小块平铺 | 大块，边缘重、中间轻 |
| 半透明角色（烟、鬼、霜）看不见 | 和底色太接近 | 加一道灰色轮廓线；结霜用 wash |
| 转场把字盖错了，或者字浮在转场上面 | 字在合成层，晚于 p5 画面 | `flash` / 擦除之前先 `flushLetters()` |
| 手里拿的牌子、号码牌上的字不跟着手动 | `letter()` 在合成层画，不跟 push/translate | 用 `toScreen()` 或 `personHandAt()` 求世界坐标，再在人物之后写字 |
| 地平线以下露出纸色 | 地面没铺满 | 地平线下补一条深色地面带 |
| 大特写时粗眉毛像墨镜（person） | 眉毛笔宽不封顶 | 眉毛宽度随 u 封顶 |
| 关灯 / 断电后人物的胸灯、光点也被压暗了 | 暗层（`flash` / 大块 wash）画在所有东西之后 | 先画暗层，再在同一位置补画光（《电动少女》`lampOver`） |
| 暗场里一只大手 / 衣袖还是亮灰色的一大块 | 它画在暗层之后 | 要随房间一起变暗的东西画在暗层之前（场景函数留一个 `o.mid` 回调） |
| 正面镜头里满屏细竖线像在下雨 | 每个木偶观众都拉一根吊线到画面顶 | 吊线只在需要揭示“被操纵”的那一章画；其余镜头不画 |
| 手放到旋钮 / 插头上，手掌把目标挡住了，像手悬在空中 | 手腕位置是猜的，手太大 | 用 `humanHandTip()` 反解手腕，让指尖正好落在目标上；手掌宽度不超过目标的 1.5–2 倍，从侧面伸进来 |
| 首尾同构图的“光点”在总览图里看不见 | 光点 glow 半径太小、颜色和夜面太接近 | 尾声光点放大到普通灯火的 2–3 倍，用和夜面反差大的颜色 |
| 人物（person）要原地旋转 | 骨架没有转身 | `sx = .32 + .68·|cos θ|`，cos < 0 时画背面，`turn = sin θ`；裙子等圆形部件按 1/sx 反压扁（《电动少女》`dianPose`） |

## 速度

| 症状 | 原因 | 做法 |
|---|---|---|
| 一帧 2 秒以上 | 水彩 fill 每次调用的固定开销大；数量太多 | 先跑 `tools/profile.mjs` 找出慢的函数（把它换成空函数比时间）。已有手段：`roofRow` 只画亮着的窗；`FILL_MIN` ✅；光晕用 wash；`vis()` 剔除画面外的物件 |
| 只裁剪大背景没变快 | 慢在 fill 的数量，不在面积 | 减少 fill 调用的次数 |
| 推镜进窗户 / 盒子开口后越推越慢，开口外还露出内层场景的溢出 | 推近时仍在画外层场景 + 整个嵌套场景 | 视野完全进入开口后直接画内层场景（kit `nestView`），无缝、省一半时间 |
| 满座观众席一帧 2–3 s | 约 150 个小人 × 十几个形状（dryrun 约 4400 个图形） | 可以接受（只占几秒）；更长的镜头里减少排数，远排只画头 |
| 满场观众（36 个背影 `clawd()`）一帧 1.3–1.6 s | 每个 `clawd()` 有好几次水彩 fill | 背影观众只用平涂（《丸之內虐待狂》`fanLite`），降到 0.2–0.7 s |
| 估计整片要渲多久 | — | `dryrun` 的图形数可以代表开销；Mac 上 3 个 worker 约 0.3–1.2 s/帧 |

## 代码

| 症状 | 原因 | 做法 |
|---|---|---|
| `Cannot access 'x' before initialization` | 同一函数里 `const` 在定义之前就被用了 | 调换顺序（dryrun 能抓到） |
| `RED is not defined`（在 timeline.js） | timeline.js 比 cast.js 先加载 | timeline 里写颜色字面量，或者把颜色放进 core / config |
| 页面卡住、不加载 | 自定义函数和 p5 全局重名（`cone`、`panorama` …） | 换名字（`trafficCone`、`greenPanorama`） |
| `pts is not iterable` 之类，只在某个镜头里出错 | 镜头函数里的局部变量叫 `paint` / `push`，把全局函数遮住了 | 局部变量别用这些名字（dryrun 能抓到） |
| `--verify` 不一致 | 用了 `Math.random`、全局变量存了状态 | 只用 `hash(i)` 和 t 的函数；跨镜头的状态放进 world.js |
| python 补丁中途失败，只改了一半 | 要替换的原文和文件对不上 | 每处替换前先 `assert old in s`；改完跑 dryrun |
| 字体缺字 | 子集字体里没有这个字 | 默认用系统楷体；用子集字体时改完文字要重跑 build_font |
| 日文字幕里假名和汉字字体不一样 | 楷体（Kaiti SC）没有假名，浏览器逐字回退到别的字体 | 日文行用 `fonts.ja`（YuKyokasho 教科书体）；双语字幕用 `subtitle.lines`（《丸之內虐待狂》） |
| beat.mjs 把 `--min/--max` 设窄后报 `undefined is not iterable` | 窄范围里没有自相关峰 | ✅ 已兜底；想指定速度直接用 `--bpm=` |

## 渲染与交付

| 症状 | 原因 | 做法 |
|---|---|---|
| 成片比渲染的帧少 1 帧 | encode 用了 `-shortest`，音轨比最后一帧短十几毫秒 | ✅ 已去掉（`--clip` 仍保留） |
| 长时间渲染时 Chrome 标签页崩溃 | 显存和内存累积 | ✅ render.mjs 每 300 帧换页，出错自动重开；`--frames` 可以断点续渲 |
| 磁盘不够 | 每帧约 530 KB，4 分钟约 3.2 GB | 开渲前 `df -h`；成片核对完以后，帧文件由老大决定删不删（我不删老大的文件） |
| 拷到桌面时报 “No such file” | 老大整理过桌面，文件夹挪进了 `MV制作/` | ✅ finish.mjs 会先在 `~/Desktop/MV制作/` 和 `~/Desktop/` 里找同名文件夹；永不覆盖已有文件 |
| 没有 numpy / Pillow / fontTools | 这台 Mac 的 python 没装这些包 | 用 node 工具（beat.mjs、finish.mjs）；sync_check 和 build_font 要另装环境 |
| ffmpeg 报 `No such filter: drawtext` | 本机 ffmpeg 没编 freetype | 总览图不加时间标签，说明“每格 4 秒，从左到右、从上到下” |
| 页面等不到 networkidle | 渲染时也在加载 `<audio>` | ✅ 只在非 `?render` 时加载音频；渲染用 `waitUntil: 'load'` |
| Cowork VM 里用不了 Mac 的 Chrome | VM 是 Linux | 让老大在终端运行 `node tools/render_watch.mjs`，往 `out/jobs/` 写 job。在 Claude Code 桌面版里直接用 Bash 后台渲染 |
| 封面只渲出左上角 1920×1080 | studio.html 的 `#out` 画布写死了 1920×1080 | ✅ cover.js 在 core.js 之前同时改 `CONFIG.width/height` 和 `#out` 的尺寸 |
| 2× 封面的线条比视频里细 | 相机 zoom 超过 1.3 时 `zsw()` 会减细墨线 | ✅ 封面期间 `SCALE_K = 1 / COVER_RES`，墨线按逻辑尺寸算 |
| 大尺寸 Clawd 脸上有几道灰白的脏印 | `bodyStrokes` 的明暗笔触在大 u 上很显眼 | 封面上用 `me(…, { plain: true })`（《丸之內虐待狂》cast.js）；新片的主角函数也留这个开关 |
| 4:3 封面右下角的东西被挡 | 平台在右下角叠时长角标 | 主角和道具放在中间偏右，右下角留空 |
| 模板占位封面渲染时打出几条 `WebGL: INVALID_OPERATION: uniform1i` | 只在 coverDemo 这种很空的画面上出现，原因没查 | 图是对的，可以不管；本片的真封面没有这条警告 |

## 流程

- 分镜要老大确认之后才写镜头代码；先做 10–15 s 样片，确认了再做全片。
- 字幕清晰的配置：size 54、粗楷体、描边 0.2·size、柔和投影、底带不透明度 150–165。字幕区在 y 960 以下，关键表演放在它上面。
- 节拍、歌词出点、自己补的连续性设定，一律写“未人工核对 / 待确认”。没有完整带声看过的，就如实说只看了拼图。
